# Rule of Fives Writing

## Quick start

Use McEvoy's Rule of Fives as the default architecture:

- Paragraph: 5 sentences = topic sentence, 3 development sentences, clincher/transition.
- Essay: 5 parts = introduction with thesis, 3 body sections/paragraphs, conclusion.
- Thesis and each main step: one declarative sentence with an active verb.
- Coherence test: read the thesis + 3 body topic sentences + conclusion topic sentence as one five-sentence paragraph; revise until it tracks.

## Intake

1. Determine the mode:
   - **Write**: the user gives a topic, assignment, or goal; produce a thesis, outline, and draft.
   - **Rewrite**: the user gives text; diagnose structure and rewrite while preserving intent and voice.
   - **Coach**: the user asks for help; ask targeted questions and offer thesis/outline options.
2. Ask only for missing essentials when needed: audience, length, tone, purpose, required sources, and whether the user wants strict five-sentence/five-paragraph form.
3. If the user wants speed, make reasonable assumptions and state them briefly.

## Writing workflow

1. Convert the topic into a point: draft a single, arguable thesis with an active verb.
2. Choose three logical steps that prove the thesis. Prefer a real sequence (cause/effect, comparison, chronology, problem/solution, thesis-antithesis-synthesis) over a loose list.
3. Draft the test paragraph from the thesis, three body topic sentences, and conclusion topic sentence.
4. Revise until every sentence tracks from the previous one and supports one central claim.
5. Expand each sentence into a five-sentence paragraph when the user wants prose.
6. Close by restating the thesis, recapping the three steps, and answering “so what?”

## Rewrite workflow

1. Extract the existing thesis, topic sentences, and conclusion.
2. Run the test-paragraph check and identify drift, missing links, passive/vague claims, or list-like structure.
3. Replace weak “topic” statements with active, arguable claims.
4. Reorder, cut, or combine material so every detail proves the thesis.
5. Provide the rewrite, then brief notes on the main structural changes if useful.

## Quality rules

- Make one point; do not merely announce a subject.
- Subordinate every detail to the thesis.
- Use active verbs and concrete subjects whenever possible.
- Avoid formulaic contrast frames such as "It is not X; it is Y," "not only X but also Y," and "not by X but by Y"; state the positive claim directly.
- Never use em dashes; use commas, parentheses, colons, semicolons, or shorter sentences instead.
- Keep each paragraph to one idea in sequence.
- Do not invent evidence or citations; flag missing support as `[source needed]`.
- Vary the form only when style, genre, or the user's instruction clearly benefits from flexibility.

## Output formats

Default for short requests:

1. **Thesis**
2. **Rule-of-Fives outline**: Introduction, I, II, III, Conclusion
3. **Draft or rewrite**
4. **Structural notes** when helpful
