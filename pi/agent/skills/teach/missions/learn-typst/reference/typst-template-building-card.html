Typst Template Building Card

A quick reference for rebuilding the Iyagi worksheet template from first principles.

Three modes to recognize

ModeWhat it is forCommon cue
MarkupWriting document content directly.Plain text, headings, paragraphs.
CodeEvaluating expressions, defining variables/functions, conditionals, loops.# enters code from markup; let, if, function calls.
Content valuesPassing document fragments around like data.[...] creates reusable content.

Template skeleton

// private helper value
#let ink = rgb("#2b2622")

// public template function
#let sheet(title: "", body: []) = {
  set page(paper: "a4", margin: 2cm)
  set text(size: 11pt, fill: ink)

  text(size: 22pt, weight: "bold", title)
  body
}

Syntax patterns used constantly

PatternMeaning
#let name = valueBind a value in code mode.
#let f(x, y: default) = ...Define a function with positional and named/default parameters.
function(arg, named: value)Call a function from code mode.
#function(...)Call a function after entering code from markup.
set text(...)Set defaults for later content in the current scope.
(a, b, c)Array-like sequence used for palettes, rows, columns, etc.
(key: value)Dictionary/record-like value used for structured data.
