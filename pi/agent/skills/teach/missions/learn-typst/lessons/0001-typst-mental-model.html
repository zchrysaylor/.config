Typst · Lesson 0001

The mental model: document as program

Your goal is to rebuild iyagi-template.typ from scratch. The first win is learning to read Typst as a mixture of markup, code, and reusable content values.

Why this matters

The template looks like a design file, but structurally it is a small program: constants define a palette, helper functions render components, and one public function assembles the page. Typst is designed for this blend: ordinary document markup plus scripting and styling rules. See the official Typst tutorial, scripting reference, and styling reference.

One thing to learn

Markup mode
Plain document content. This is where you write paragraphs, headings, emphasis, and normal prose.
Code mode
Expressions, bindings, functions, conditionals, loops, and calls. From markup, # enters code.
Content values
Document fragments can be passed as values. In the template API, korean: [ ... ] means “pass this content fragment.”

Read this tiny template skeleton

// Private helper value.
#let ink = rgb("#2b2622")

// Public template function.
#let sheet(title: "", body: []) = {
  set page(paper: "a4", margin: 2cm)
  set text(size: 11pt, fill: ink)

  text(size: 22pt, weight: "bold", title)
  body
}

#sheet(
  title: "First Story",
  body: [안녕하세요. This is reusable document content.],
)

Principle: #let defines values, functions turn repeated layout into reusable components, and set rules establish defaults for following content in their scope. This is the same pattern your real template uses with ii-ink, ii-badge, ii-section, and iyagi-sheet.

Practice: classify the syntax

Choose the best classification for korean: [ ... ] in the public API example.

Your first rebuild step

Create a scratch file anywhere you like, for example:

mkdir -p /tmp/typst-iyagi
$EDITOR /tmp/typst-iyagi/sheet.typ

Then write your own version of the tiny skeleton above from memory, but change the names and values. Your target is not visual beauty yet; it is proving you understand:

  • one helper constant,
  • one public function with named defaults,
  • one set page rule,
  • one set text rule,
  • one content parameter rendered inside the function.

Compile with:

typst compile /tmp/typst-iyagi/sheet.typ

Self-check before moving on

Paste your scratch skeleton here and check whether it contains the five structural pieces. This is not a Typst compiler; it is a quick structural checklist.
