# Mission: Typst

## Why
Learn Typst well enough to rebuild and confidently modify the `iyagi-template.typ` Korean story worksheet template from scratch, using principles and syntax rather than line-by-line copying.

## Success looks like
- Explain the difference between Typst markup, code mode, content values, functions, and show/set rules.
- Recreate the template in small layers: page setup, typography, reusable section components, tables, optional sections, and layout measurement.
- Debug and extend the template without relying on vibe-coded guesses.

## Constraints
- The learner already knows several programming languages, so lessons can lean on programming analogies.
- Start from zero Typst knowledge.
- Prefer principle-first guidance with small exercises over exact transcription.

## Out of scope
- Building a full general-purpose Typst package immediately.
- Deep typography theory beyond what is needed for this template.
