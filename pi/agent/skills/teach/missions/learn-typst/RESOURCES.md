# Typst Resources

## Knowledge

- [Typst Documentation](https://typst.app/docs/)
  Official reference for Typst syntax, functions, layout, text, tables, scripting, and package behavior. Use for: grounding every syntax and API claim.
- [Typst Tutorial](https://typst.app/docs/tutorial/)
  Official guided introduction to Typst's markup/code model. Use for: beginner mental models and first examples.
- [Typst Reference: Scripting](https://typst.app/docs/reference/scripting/)
  Official reference for variables, functions, arrays, dictionaries, loops, conditionals, and closures. Use for: understanding the template as a program.
- [Typst Reference: Styling](https://typst.app/docs/reference/styling/)
  Official reference for set rules, show rules, and styling scope. Use for: page/text/paragraph defaults in the template.
- [Typst Reference: Layout](https://typst.app/docs/reference/layout/)
  Official reference for blocks, boxes, grids, alignment, spacing, measurement, and page layout. Use for: rebuilding the visual structure of the worksheet.
- [Typst Reference: Table](https://typst.app/docs/reference/model/table/)
  Official reference for table construction, cells, strokes, fills, headers, and lines. Use for: grammar and vocabulary tables in the template.
- [Typst GitHub Repository](https://github.com/typst/typst)
  Source repository and issue discussions. Use for: implementation details, release notes, and clarifying behavior when docs are ambiguous.

## Wisdom (Communities)

- [Typst Forum](https://forum.typst.app/)
  Official community forum. Use for: idiomatic solutions, debugging layout issues, and design-pattern feedback.
- [Typst Discord](https://discord.gg/2uDybryKPe)
  Active community chat linked from the official Typst project. Use for: quick questions and real-world examples.
